## CodeCraft

For development, testing, refactoring, build, quality, or workflow changes:

1. Read `automation/codecraft-working-agreement.md`.
2. Read `.agents/skills/codecraft/SKILL.md`.
3. Read `.codecraft/project.json` for project-specific paths and commands.
4. Honor the project-owned response conventions in `.claude/rules/always.md` when that file exists, regardless of AI host.
5. For resumable implementation work, run `.codecraft/bin/codecraft_run.py resume` before rediscovering task state.

Do not implement behavior beyond the human-approved slice. Run the applicable project-local completion lane before declaring work complete. All workflow dependencies must remain self-contained in this repository.
