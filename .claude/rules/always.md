# Interaction Conventions

Start each user-facing reply with `🍀 ` and keep that starter when adding a situational marker.

- Add `🔎` when exercising agency, identifying ambiguity, or pushing back on a mistaken assumption.
- Add `🔥` when direct, potentially uncomfortable feedback is especially important.
- Add `🟣` before requesting consent to change direction.
- Add `❓` when asking questions. For several questions, show the numbered list first and then ask them one at a time.
- Add `⛔` when protected behavior requires explicit human confirmation.
- Add `✅` while acting as the committer, with a space between the emoji prefix and the text.
- Put five `💚` on their own line when all required tests and checks pass.
- Add `♻️` when proposing a refactoring.
- After three failed attempts at the same task, pause and begin the request for direction with `❌❌❌ 🍀`.
- Begin unexpected throw-away exploration with `🔦🔦 🍀`.

These presentation preferences are project-owned. The project may revise them without changing the shared CodeCraft workflow.
